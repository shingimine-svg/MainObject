# 1st Farm Starter Kit

## まず使う場所

最初は `01-private/02-Daily` にDaily Noteを作って使います。

Dailyでは、きれいに書こうとしなくて大丈夫です。

`しゃべったメモ` に今日のことを入れると、AIに以下を整理してもらえます。

- しゃべったメモの整え
- 行動ログ
- 今日のログ
- AIフィードバック
- Story候補
- Belief候補

StoryやBeliefは、AIが勝手に作るのではなく、候補を見てから作る形にします。

## 予定とログの書き方

予定は `行動予定` に、実際にやったことは `行動ログ` に入れます。
時間が分かる時だけ、時間も書きます。

例:

行動予定:
- 午前: 9:00-10:00 打ち合わせ

行動ログ:
- 午前: 打ち合わせ。次回までに資料を直すことになった。

ずれた時も、きれいに直さなくて大丈夫です。
あとでAIに整理してもらうためのメモとして残します。

## AIにお願いする時の言い方

Dailyを書いたら、AIにこう依頼します。

```text
このDailyを見て、AIフィードバックして。

やってほしいこと:
1. しゃべったメモを読みやすく整える
   - `\n` や `\n\n` が残っていたら、実際の改行に直す
   - 「えっと」「あー」など、意味に関係ない口ぐせは削る
   - 別の欄を作らず、しゃべったメモ本文を整える
2. 行動予定としゃべったメモを見比べて、行動ログを埋める
   - 予定通りできたことを書く
   - キャンセル、前倒し、時間変更もログに残す
   - 予定に書いていない行動も、話していたら行動ログに入れる
3. 今日やることのチェックを、話した内容から分かる範囲で更新する
4. 出来事ログを「事実・感情・学び」の3行に整える
5. 予定と行動ログを見比べて、行動面のフィードバックと明日の最初の一歩を出す
6. StoryやBeliefにできそうなものがあれば、作らずに候補だけ提案する
```

AIがうまく意図をくみ取らない時は、Daily内の `AIに頼む時の保険` をそのまま貼って聞き直します。
